
# Análise de Feedbacks Escolares

Este projeto foi desenvolvido com o objetivo de colocar em prática meus conhecimentos em desenvolvimento web, manipulação do DOM e organização de informações utilizando JavaScript.

A aplicação permite visualizar e filtrar feedbacks escolares, facilitando a consulta de respostas discursivas coletadas por meio de formulários.

## Sobre o projeto

A proposta surgiu da necessidade de organizar feedbacks de alunos e facilitar a identificação de comentários relacionados a diferentes áreas do conhecimento.

Por meio de uma interface web simples, é possível consultar as informações e utilizar filtros para localizar respostas específicas.

## Funcionalidades

- Visualização de feedbacks escolares
- Filtragem de comentários por palavra-chave
- Organização dos feedbacks por áreas do conhecimento, como Linguagens, Exatas e Humanas
- Atualização dinâmica dos resultados apresentados na interface

## Tecnologias utilizadas

- **HTML:** estrutura da aplicação
- **CSS:** estilização da interface
- **JavaScript:** manipulação do DOM e implementação dos filtros

## Como executar

1. Clone o repositório ou baixe os arquivos pelo GitHub.
2. Abra o arquivo `index.html` no navegador.
3. Utilize os filtros disponíveis para consultar os feedbacks.

A aplicação utiliza tecnologias web e pode ser executada localmente, sem necessidade de instalar dependências adicionais.

## Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Manipulação de elementos do DOM
- Implementação de filtros dinâmicos com JavaScript
- Organização e apresentação de informações textuais
- Construção de interfaces com HTML e CSS
- Interatividade em aplicações web

Este é um projeto de estudos voltado à aplicação de conceitos de desenvolvimento frontend e organização de informações.
